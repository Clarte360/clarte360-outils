# Clarté360 — Boucle auto-validante

Outil de séance accompagnateur.

- Accès par code accompagnateur.
- JSON général contenant plusieurs bénéficiaires.
- Identification bénéficiaire : nom, prénom, date de naissance.
- Ajout de croyances à tout moment de la découverte.
- Phase 3 : repérage, validation, boucle auto-validante.
- Phase 6 : sélection, scénario de sortie, mini-plan d'action.
- Export JSON général et PDF par croyance.

Les codes accompagnateurs sont entre les balises :
`CLARTE360_CONSULTANT_CODES_START` et `CLARTE360_CONSULTANT_CODES_END`.
