# Clarté360 - Recherche de mes valeurs V2.1.0

Version complète construite à partir de la V2.0 préproduction, du Canvas V2.1 final et du Framework Clarté360 mis à jour.

## Évolutions majeures

1. Code de déblocage FW-303 pour les nouvelles passations.
2. Reprise intelligente après import du JSON de travail.
3. Priorité aux valeurs découvertes entre deux connexions.
4. Navigation vers les étapes déjà ouvertes et conservation des dépendances.
5. Synchronisation des valeurs validées dans la mémoire, le panneau, le JSON et le rapport.
6. Relances automatiques limitées en cas d'interruption temporaire de l'API.
7. JSON final épuré, non réutilisable pour reprendre les questionnaires.
8. Mode consultation et réimpression sans appel API.
9. Clôture définitive avec double confirmation et remise des documents.
10. Choix entre envoi automatique du JSON final et remise manuelle à l'accompagnateur.
11. RGPD mis à jour pour la voix, l'IA, le contrôle d'accès et la transmission.

## Compatibilité

Les JSON de travail V2.0 restent importables. Les JSON finaux V2.1 sont automatiquement reconnus en lecture seule.
