# CLARTÉ360 PIP RIASEC / O*NET - RAPPORT JALON E
Date : 18/09/2026

## Base
Développement réalisé exclusivement à partir du Jalon D officiel récupéré depuis OneDrive.

## Périmètre E - rapport PDF professionnel
- Générateur PDF `clarte360_pip/reporting.py`, version `PIP-RPT-1.0`.
- Identité visuelle Clarté360, pagination et métadonnées.
- PIP : classement des six dimensions, indices 0-100, graphique, code Holland uniquement s'il est non ambigu, descriptions des trois dimensions dominantes.
- Limites explicites : intérêts et non compétences/aptitudes/intelligence ; aucune prescription de métier.
- O*NET : section séparée seulement si la passation O*NET est terminée ; scores officiels conservés sur leur échelle propre.
- Comparaison PIP/O*NET strictement descriptive par rang ; aucune fusion, moyenne ou score composite.
- Ressenti : section séparée lorsqu'il est disponible ; il ne modifie jamais le scoring.
- Repères finaux : mise en perspective avec valeurs, compétences, expériences, contraintes, motivations, environnement et projet, sans prétendre que le PIP les mesure.
- PUBLIC et ACCOMPAGNEMENT : téléchargement du rapport PDF à la fin du parcours ; le JSON PUBLIC reste disponible comme sauvegarde technique.
- Génération locale sans dépendance réseau.

## Hors périmètre de E
- Les pistes de métiers ROME seront intégrées au Jalon F, conformément au découpage validé.
- La transmission/référence documentaire complète vers Gestion des Actions relève du Jalon G.
