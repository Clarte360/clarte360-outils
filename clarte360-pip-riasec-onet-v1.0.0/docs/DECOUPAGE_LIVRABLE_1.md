# Decoupage definitif du Livrable 1

- **L1-A - Socle + architecture PIP** : Framework V4 modularise, structure applicative, modes d'entree, session, RGPD, sauvegarde technique, configuration, tests, sources PIP embarquees pour cumul.
- **L1-B - Donnees + moteur PIP** : publication controlee du tableur maître vers runtime, 120 items pilotes, validations structurelles, moteur de passation et echelle fermee, sans feedback intermediaire.
- **L1-C - Scoring + persistance + parcours** : scoring deterministe, six scores, egalites/code Holland prepare, sauvegarde/reprise métier, parcours PIP seul/PIP puis O*NET avec verrou anti-restitution, ressenti au moment defini.
- **L1-D - Consolidation Livrable 1** : audit complet, regression, Linux/VPS, secrets, imports, nettoyage, documentation et checklist de recette utilisateur.

Ce decoupage couvre le socle PIP et le moteur PIP du CDC (lots I1 et I3) ainsi que les gardes de parcours necessaires au Livrable 1, sans anticiper les integrations completes I2, I4, I5, I6 et I7.
