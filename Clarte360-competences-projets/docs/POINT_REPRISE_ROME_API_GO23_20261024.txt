## Décision fonctionnelle ROME

Le choix de 1 à 3 métiers se fait dans l’application, accompagné par l’intervenant. Le bénéficiaire ne doit pas effectuer de recherche ROME externe. Les métiers sont examinés et confirmés explicitement en séance; l’IA prépare des pistes mais ne valide rien.

Le cœur du travail est de confronter les savoirs, savoir-faire et savoir-être ROME aux éléments du parcours élargi, expérience par expérience. L’intervenant peut cocher plusieurs attendus, relier chacun à une ou plusieurs expériences/études/formations/apprentissages personnels, puis enregistrer le statut et le niveau discutés avec le bénéficiaire. Un diplôme n’est présenté comme obligatoire que si une source officielle établit cette obligation; une rubrique « accès au métier » du ROME ne suffit pas.

## API ROME — état exact

- GO-11/GO-12 demandent les quatre familles souscrites séparément : Métiers, Compétences, Contextes de travail et Fiches métiers. Les clients présents utilisent des scopes distincts et contrôlent les codes retournés. Le chargement d’une fiche par code passe par l’API Fiches métiers.
- La recherche textuelle appelle maintenant les deux opérations officielles ROME Métiers d’autocomplétion : métiers `GET /v1/metiers/metier/requete` (`q`, `champs=code,libelle`) et appellations `GET /v1/metiers/appellation/requete` (`q`, `champs=libelle,code,metier(code,libelle)`). Les appellations sont reliées au code et au libellé du métier parent. Si l’API échoue ou ne retourne rien, le snapshot local v61 / 26M06, publié le 15/06/2026, sert de secours (1 911 codes issus du `05-RefRomeXml.zip`). Ce snapshot est daté et n’est pas présenté comme complet/courant. France Travail affichait 1 923 fiches dans sa publication du 19/10/2026, avec une prochaine actualisation prévue en mars 2027.
- La recherche s’envoie avec un bouton; les appels GET du client sont espacés d’au moins 1,05 seconde pour respecter la limite ROME d’un appel par seconde.
- Un champ « Code ROME direct » appelle l’API Fiches métiers, même lorsque le code n’existe pas dans le snapshot local. Les deux opérations de recherche textuelle sont raccordées à partir de la documentation officielle; les routes et sélecteurs `champs` suivent leurs réponses respectives.
- La fiche ROME/RIASEC Excel est une table de correspondance d’intérêts, pas le catalogue des compétences. Le ROME doit servir au rapprochement métier; les ressources d’investigation du bénéficiaire restent disponibles, sans recherche externe imposée pour le choix de code.
- Aucun appel France Travail réel n’a été effectué depuis cette candidate : le coffre VPS et les scopes configurés ne sont pas accessibles dans cet espace. Le diagnostic synthétique des quatre familles est `tools/test_france_travail_rome_all.py`.
