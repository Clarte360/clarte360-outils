# Audit validation des saisies — Moteurs professionnels 1.8.1

Durcissement des identités, e-mails, téléphone, contact support, code à 6 chiffres, positions 0–10, identifiants techniques et reprise JSON. Le JSON est limité à 2 Mo et contrôlé avant restauration. Les curseurs inconnus, doublons, valeurs hors bornes et structures malformées sont refusés avec un message utilisateur.

Le questionnaire, ses 60 curseurs, les dimensions, le scoring et les interprétations n'ont pas été modifiés.
