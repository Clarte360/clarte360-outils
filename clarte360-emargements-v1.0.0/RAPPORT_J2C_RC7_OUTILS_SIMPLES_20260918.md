# RC7 — Outils Clarté360 simplifiés

- Suppression de l'affichage des versions dans l'interface métier.
- Mode d'accès verrouillé : PIP signé, autres outils autonomes en lien direct.
- Plus aucun filtre par type de prestation.
- Activation / prescription d'un outil existant enregistrées automatiquement.
- Un outil désactivé ou non prescriptible est retiré des autorisations d'actions.
- Les métadonnées de version restent internes et n'interviennent pas dans l'éligibilité.
