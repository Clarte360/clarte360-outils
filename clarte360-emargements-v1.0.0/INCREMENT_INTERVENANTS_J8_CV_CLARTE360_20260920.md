# J8 - CV Clarté360
Date : 20/09/2026

## Objet
Générer depuis le dossier professionnel 360° deux CV PDF distincts : INTERNE et CLIENT.

## Réalisé
- nouvel onglet `CV Clarté360` dans le dossier professionnel ;
- génération PDF avec identité Clarté360 ;
- version INTERNE : coordonnées professionnelles, collaboration, conformité utile et notes internes ;
- version CLIENT : exclusion des coordonnées personnelles, notes internes et données administratives non nécessaires ;
- expériences, diplômes/formations, certifications/habilitations, langues, spécialités ;
- prestations Clarté360 : uniquement qualifications HUMAINES validées ; aucune proposition IA non validée ;
- historique/versionnage des générations avec empreinte SHA-256, auteur et date ;
- aucun contenu ou compétence inventé par le générateur.

## Garde-fous
La génération est déterministe à partir du dossier 360°. Elle ne demande pas à l'IA de rédiger ou d'enrichir le CV. Une donnée absente reste absente.
