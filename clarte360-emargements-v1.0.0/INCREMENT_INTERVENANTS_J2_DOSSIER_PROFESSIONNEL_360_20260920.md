# J2 — Dossier professionnel 360°

Base : J1R Prestations V1.

## Livré
- dossier unique `professional_person_id`, sans création d'un trainer opérationnel pour un candidat ;
- profil professionnel structuré : titre, résumé, contacts, localisation, collaboration, site/LinkedIn, notes internes ;
- expériences et spécialités ;
- diplômes/formations ;
- certifications, habilitations et attestations ;
- langues et niveaux/preuves ;
- documents professionnels : CV, photo, diplôme, certification, habilitation, attestation, RC Pro, référence, autre ;
- stockage documentaire dédupliqué par hash sur le stockage commun ;
- interface admin à onglets avec liste ouvrant directement le dossier ;
- création manuelle d'un CANDIDAT dans le même référentiel que le futur intervenant.

## Garde-fous
- aucune qualification n'est inventée ;
- aucun candidat n'est rendu affectable ;
- aucune liaison Formation/Actions n'est modifiée à ce jalon ;
- aucun portail public n'est créé ;
- aucune logique IA n'est introduite ;
- les anciens intervenants restent reliés à leur identité historique J0.

## Suite
J3 : workflow CANDIDAT → INTERVENANT, complétude, demandes de complément et décision administrateur.
