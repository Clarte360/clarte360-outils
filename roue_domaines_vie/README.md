# Clarté360 - Roue des domaines de vie

Application Streamlit d'exploration des domaines de vie : roue actuelle, roue idéale sans contrainte, comparaison et pistes d'action.

## Lancement local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Fichiers
- `app.py` : application principale
- `assets/logo_clarte360.png` : logo
- `.streamlit/config.toml` : thème Clarté360
