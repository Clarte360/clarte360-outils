# Clarté360 - Préférences professionnelles

Version : v1.9.4-socle-clarte360

Application Streamlit propriétaire Clarté360 alignée sur le socle commun.

- Accueil standard JSON / nouvelle session
- RGPD et traçabilité
- Code d'accès par email
- Sauvegarde et reprise JSON
- Timeout bénéficiaire 15 minutes
- Rapport PDF avec pied de page institutionnel
- Transmission automatique du JSON final à Clarté360 si SMTP configuré

Logique métier Préférences professionnelles inchangée.
